# Terminology

The Night ecosystem is organized around libraries and services.

- **Library**: A reusable package that applications integrate directly.
- **Service**: A hosted capability accessed over a network boundary.
- **Guide**: A task-focused document for using Night products together.
- **Reference**: Definitive technical detail such as APIs, configuration, and protocols.

Individual product documentation defines any additional terms that are specific to that product.
