# MoonScale API

`MoonScaleClient` provides tailnet TCP and UDP dials and listeners, exit-node controls, `fetch()`, DNS resolution, Funnel controls, and lifecycle shutdown. See [MoonScale API reference](/moonscale/api-reference/) and [MoonScale integration](/moonscale/integration/). `fetch()` and `createTailscaleWebSocket()` use `InsecureSkipVerify`; see [MoonScale security](/moonscale/security/).
