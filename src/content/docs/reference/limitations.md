# Limitations

Use product limitation pages when choosing an integration: [Dusk](/dusk/limitations/), [MoonBeam](/moonbeam/limitations/), [Nova](/nova/limitations/), [MoonScale](/moonscale/limitations/), and [Eclipse](/eclipse/limitations/).

In particular, MoonScale TLS APIs use `InsecureSkipVerify`, Nova has explicit browser compatibility caveats, and Eclipse persistence depends on browser worker, storage, and cross-origin-isolation support.
