# DPM Commands

DPM 1.0.0 exposes browser WASM help, DPM/npm install aliases, and `npm exec` planning; it does not install a native CLI. See [DPM installation and use](/dusk/dpm/installation-and-use/) and the [DPM overview](/dusk/dpm/).
