# DPM Configuration

The DPM 1.0.0 browser core has no `config` command and does not read `.dpmrc` or `.npmrc`. Direct installs accept an HTTPS `--registry` argument or `DPM_REGISTRY` in the execution context, with the command argument taking precedence. See [DPM configuration](/dusk/dpm/configuration/).
