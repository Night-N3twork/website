# LunaSSH API

`SSHClient` initializes the Go/WASM runtime and opens sessions through direct Wisp or MoonBeam relay transports. Sessions can send bytes, resize the terminal, and disconnect. Connection options include password or private-key authentication and host-key verification settings. See the full [LunaSSH API reference](/lunassh/api-reference/) and [LunaSSH security guidance](/lunassh/security/).
