# Eclipse

Eclipse is the Night ecosystem's virtual-machine entry. It hosts a browser VM with TCP and UDP egress through a user-supplied Wisp server.

The runtime combines a virtual LAN gateway, Wisp client, egress policy, QEMU networking adapter, and hosting shells. Use the [installation](./installation/) guide for the demo, then review [architecture](./architecture/) and [operations](./operations/) before deploying it.
